
# AI Analysis Evaluator

An automated evaluation framework for assessing the accuracy, reliability, and consistency of AI-generated data science analyses.

## Overview

This project demonstrates how structured evaluation techniques can identify errors in AI-generated analytical reports.

## Key Features

- Detection of potential data leakage
- Identification of inconsistent model metrics
- Validation of training and testing dataset overlap
- Detection of unsupported analytical conclusions
- Automated evaluation using Python
- Unit testing through GitHub Actions

## Technologies

Python | JSON | unittest | GitHub Actions
